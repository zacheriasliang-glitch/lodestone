# Source-bound re-entry fold

See [the public tutorial and commands](../../docs/origami-fold.md).

`src/origami_fold.py` provides orient, expand, refresh, render, verify and rebind.
`src/build_example.py` creates a new self-contained example and demonstrates an
explicit source mapping. `examples/demo` is invented and grants no authority.

Python 3.10+; standard library only. Git observations are optional. Tests use
temporary fixtures. Personal workstream mappings and their source corpus are
not included.
