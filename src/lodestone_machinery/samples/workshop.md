# Ceramic workshop: operating note

The ceramic workshop records each test tile's clay body, glaze batch, application thickness, firing schedule, and observed surface. A label links the physical tile to its entry. Missing firing information remains unknown.

Before a ceramic repair decision, inspect the actual surface and the test record. A complete record makes comparison possible; it does not establish that the glaze performed well.

This file is fictional example material for a source-selection demonstration. It is not kiln-operation advice or a record from any real studio.
