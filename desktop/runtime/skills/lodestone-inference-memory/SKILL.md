Read applicable native SEED/NACRE conditions, outcomes and corrections. An RSS stop
does not identify its allocation cause. Use the matching package and
`docs/loom-inference-memory.md` for routes and evidence limits.

Measure the full prompt with the pinned tokenizer and reserve output; preserve
teaching, conditions, corrections and history. Verify exact reconstruction after
representation changes. `lodestone loom-tools inference-memory assess --file
INPUT.json` estimates geometry without loading a model; it cannot guarantee RSS fit.

The helper uses bounded prompt chunks, initialized-prefix cache views and
per-KV-head SDPA to avoid full repeated K/V copies. Instance bindings are restored.
It supports Qwen3 full attention, CPU float32, Torch 2.2.2, Transformers 4.51.3
and one unpadded greedy sequence. Reject incompatible conditions. Fixture agreement
does not prove pretrained numerical equivalence. These conditions and the 4 GiB
budget belong to this implementation, not all organs.

Keep complete input, positions, numeric format and generation settings across
comparisons. Retain actual output, refusal/interruption, stop reason, cleanup and
correction. Frozen studies stay separate. Loading this skill starts no model call,
retry, cap increase, truncation, provider switch, training or installation.

Export with `lodestone loom-tools inference-memory candidate --output NEW.json`;
use `loom-practice improve` to propose, inspect/materialize, prepare, run and review
one selected trial under independent wall/RSS/process-group supervision. Check full
native packet size as well as artifact size. Materialization executes nothing.
For a trusted evaluator that decodes and validates the complete snapshot, use
`improve run --pack-tool-context` when full source lineage exceeds the text envelope.
Source stays readable in retained artifacts. Packing changes tool transport, not
the model's context, and retains all outcomes and corrections.
Existing user authorization persists. Never edit an installed versioned runtime in place.
